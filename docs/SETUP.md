# Detailed Setup Guide

This guide provides detailed instructions for setting up the project from scratch.

## 1. Prerequisites
-   **Python:** Ensure you have Python 3.9 or newer. You can check with `python --version`.
-   **Git:** Ensure Git is installed. You can check with `git --version`.
-   **OpenAI API Key:** You must have an API key from OpenAI. [Get one here](https://platform.openai.com/account/api-keys).

## 2. Cloning the Repository
Open your terminal or command prompt and navigate to the directory where you want to store the project.

git clone [https://github.com/Vaishnavi-1376/Group-Y.git](https://github.com/Vaishnavi-1376/Group-Y.git)
